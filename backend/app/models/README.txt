ARCHITECTURE NOTES:
All models are built around the Tenant model which provides multi-tenancy isolation, with every data model including a tenant_id foreign key for security. The Job and JobStep models form the core of the scheduling system, with Employee and Machine models providing the resources that get assigned to work. Skills create a many-to-many relationship between employees/machines and job requirements. The models are designed to support the pure Python scheduler engine by providing clean data structures without embedded business logic.
